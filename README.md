# Savdo — Instagram Usernames Marketplace (Telegram Mini App)

Маркетплейс Instagram-юзернеймов внутри Telegram-бота [@savdouser_bot](https://t.me/savdouser_bot).

## Что это
Полностью статичный Telegram Mini App (без сервера): данные хранятся в `localStorage` устройства пользователя.
Хостится на GitHub Pages, бесплатно, без использования кредитов Base44.

## Функции
- Главная: поиск, категории, промо-баннер карусель, Featured Listings
- Лента всех лотов с фильтрами по категориям
- Мои лоты: создание нового лота, избранное
- Страница лота: 3 способа продажи (купить сейчас / оффер / аукцион с анти-снайпингом),
  индекс редкости (кольцо-прогресс), трекер эскроу-сделки, график истории цены, похожие лоты,
  встроенный чат с маскировкой контактов, отзывы, Boost
- Профиль: тёмная тема, 3 языка (RU / UZ / EN), реферальная ссылка
- Админ-панель — видна и доступна **только** Telegram ID `8396883978` (сверка `Telegram.WebApp.initDataUnsafe.user.id`,
  либо `?uid=` в адресной строке при тестировании вне Telegram)
- PWA: `manifest.webmanifest` + `sw.js` для установки на экран и офлайн-доступа к интерфейсу

## ⚠️ Важно про безопасность админки
Это чисто клиентское приложение (GitHub Pages не исполняет серверный код), поэтому проверка Telegram ID
происходит в браузере — она скрывает админ-кнопку от обычных пользователей, но не является криптографической
защитой (как если бы её проверял сервер по подписи `initData`). Для реальной защиты денег/данных в будущем
нужен отдельный backend, который проверяет подпись `initData` по секрету бота.

## Настройка Telegram
1. Включить GitHub Pages (Settings → Pages → Source: `main` / root).
2. У бота `@savdouser_bot` выставлена кнопка меню на URL Pages (см. ниже).
3. Открыть бота в Telegram → кнопка меню открывает мини-апп.

## Структура
- `index.html` — всё приложение (HTML/CSS/JS в одном файле)
- `manifest.webmanifest` — PWA манифест
- `sw.js` — service worker (офлайн-кэш шелла)

Сервис не связан с Instagram и Meta Platforms, Inc.
